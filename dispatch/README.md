# 双 8 狂飙 · 小小高铁调度员（MVP）

独立调度页面，复用原版的高铁车体和双 8 字环线。原版 14 列车射击、连挂、武器、技能及 4/5 道岔键保持原样。

本版以一列双节高铁演示四个道岔、连续跨线、红灯等待和整列车通过后的道岔解锁。不是多列车调度系统，也不是实际铁路操作仿真。

## 打开运行

1. 下载 **此 PR 分支的完整仓库 ZIP** 并解压。
2. 双击 `dispatch/index.html`，用支持 WebGL 的 Chrome、Edge 或 Safari 打开。全部脚本在本地，无 CDN、无账号、无构建步骤。
3. 根目录 `index.html` 和 `双8狂飙/开始游戏.html` 顶部也有「高铁调度模式」入口。若单独转发原版 HTML，原版仍可离线运行；要使用新增入口，请保留完整目录。

手机建议通过静态服务器打开。电脑在仓库根目录运行：

```sh
python3 -m http.server 8765
```

电脑访问 `http://localhost:8765/dispatch/`；同一局域网手机访问 `http://电脑局域网IP:8765/dispatch/`。需要电脑防火墙允许该端口。页面没有音频、外部请求或触摸手势依赖。

## 儿童验收流程（约 3 分钟）

| 操作 | 预期结果 |
| --- | --- |
| 点击「从车站开始连续演示」 | G01 从开心站出发，经 1→2 到右线，经 3→4 回左线；车头与后车厢连续沿轨道运动 |
| 观察两个车站 | 每次到站停 3 秒，自动继续；跨线次数、到站次数增加 |
| 点击「停车」 | 退出自动演示并减速停车；可接管道岔 |
| 点击「重来」，将 2 号切成直行，其余保持跨线，再发车 | 1 号前红灯，高铁在道岔前减速等待 |
| 等车停稳后，将 2 号切回跨线 | 道岔先完成转换，然后信号放行；高铁继续跨线 |
| 在跨线前后尝试切换 1、2 号 | 进路锁定后按钮显示锁；车头离开时仍锁定，车尾完全离开后解锁 |
| 重来，将 1、4 号都切成直行，再发车 | 列车继续绕左环线，回到开心站停车，不跨线 |
| 点击「暂停画面」，再继续 | 列车、道岔转换和演示停站计时一起冻结/恢复 |
| 在手机上旋转屏幕、滑动页面、点击四个道岔 | 无横向溢出；画面可旋转、按钮可点击；控制台在画面下方 |
| 返回原版，开始游戏，按 4/5，再发射武器 | 原射击玩法继续正常运行 |

调度页快捷键：`1–4` 对应四个道岔，`Enter` 发车，`S` 减速停车，`Space` 暂停画面。已聚焦按钮上的 Enter/Space 保留原生点击行为。原版快捷键不变。

## 路径与状态契约

| 道岔 | 位置 | 跨线时的配对 |
| --- | --- | --- |
| 1 | 左环线出岔 | 与 2 对齐，进入上层联络桥 |
| 2 | 右环线入岔 | 接收 1→2 的跨线列车 |
| 3 | 右环线出岔 | 与 4 对齐，进入下层联络桥 |
| 4 | 左环线入岔 | 接收 3→4 的跨线列车 |

- 两端未对齐或道岔转换尚未完成时，列车在距道岔中心 12 个场景单位处停下，车头不会越过道岔。
- 进入制动接近区域后，如果进路可用，锁定该进路。直行只锁本岔；跨线同时锁出岔与入岔。停在进路中也不解锁。
- 锁定后分支选择固定。车头经过入岔后还需走 24 个场景单位，涵盖车厢和余量，才释放跨线两端道岔。
- 入岔处于跨线位置时，沿本环线到达的列车同样必须等待；不会从错误分支强行挤过。
- 车体位置来自实际走过的分段轨迹，后车厢取车头后方 9.3 个场景单位的历史位置。它不会根据当前道岔重新选路。
- 道岔动画、UI、信号灯、跨线高亮均读取同一个调度状态。四个接头的位置一致，端点切线连续。
- 切到后台自动暂停。返回页面后手动继续，不会把离开期间的时间累加成列车跳跃。

## 文件与复用边界

- `engine.js`：独立调度状态机、锁定、制动与历史轨迹；不含战斗逻辑。
- `layout.js`：复用原源码双 8 的采样公式；把两条联络线改为四个分立端点。两条联络桥上下分离。
- `train-model.js`：复用原版 `bodyGeometry` / `makeCar`，更换蓝白材质，不挂载武器、火焰或损伤效果。
- `app.js` / `style.css` / `index.html`：3D、信号、触控和键盘操作。
- `vendor/three.min.js`：从原版 HTML 原样提取的内嵌 Three.js，许可见 `vendor/LICENSE-three.txt`。保留原版库版本，避免这次改动引入升级风险。
- 两个原版 HTML 只各增加一个链接。原有两段脚本已与基线 `07ec551048326e848fb145142a57461b0c938f95` 比较，字节一致。

边界：单列车、单向行驶，无会车、闭塞分区、冲突进路争用或真实时刻表；两组独立联络线的四个单开道岔，不是铁路工程上的复式交分道岔。保留原游戏夸张坡度、桥梁和车体比例，显示的是动画速度，不能解读为真实 km/h。
