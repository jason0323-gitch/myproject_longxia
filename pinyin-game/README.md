# 拼读闯关：离线陪练开发版

这是可运行的第一版，不是原 PRD v1.6 的全功能验收版。尚尚产品流程与石头 UI 建议已落实；尚未上线生产。

## 使用

用桌面 Chrome 打开 `dist/拼读闯关-读一读二.html`。界面、词表、18段候选录音都在单文件内，无外部资源依赖。iPhone 文件预览不保证运行 JavaScript，移动端浏览器体验仍待真机验收。

本版18段整词音已由本次陪练家长试听接受，可直接播放，不要求重复勾选。接受状态与具体录音绑定，替换或新增声音仍需复核；家长可随时取消使用。缺音词由家长带读。不要把候选音标为已校准。三遍流程为跟读、自主读、选择后再朗读；完成记录区分自行确认、家长自主确认、带读和浏览器文本匹配。

## 本版包含

- 首页、三站进度、每站覆盖当前全部词表、暂停继续。
- 4种第三关选择题；错选词复现；带读兜底，不锁死孩子。
- 三档奖励、独立游戏星、泡泡游戏、动效强度和减少动态效果。
- 家长设置、词表编辑、单文件导出、进度 JSON 备份/导入、报告、打印打卡与奖状。
- 18段真人整词候选录音、0.8倍保调慢播、音频导入、解码自检。
- 默认离线人工陪练。可选 Chrome 文本识别，须本次明确监护人同意，页面不保存儿童录音及转写。

## 开发与验证

```
python3 build.py
node --check src/app.js
node tests/logic.cjs
node tests/browser.cjs
```

源码分成词表、样式、行为与模板，构建仍输出单HTML。浏览器测试需要 Playwright 和 Chromium，测试脚本默认 `/usr/bin/chromium`。本次逻辑模拟30项通过；浏览器启动被执行环境的 socket/ptrace 限制阻止，未声称截图、真机或麦克风通过。详见 `TEST-REPORT.md`。

## 数据与安全

本机 localStorage 保存进度；移动文件、更换浏览器或清缓存可能丢进度，建议导出备份。备份含昵称和练习记录，不可公开提交。导出HTML包含词表及全部导入音频，请勿导入儿童录音后公开分享。

网络识别默认关闭，每次重开需明确同意。Google/Chrome 的实际留存和训练条款未作不留存保证。讯飞密钥、个人信息和儿童音频不进入此仓库。

## 后续加固

从零搭建，不依赖原HTML。音频复核与具体录音内容绑定，替换录音后须重新复核；增加声母/韵母分色，午夜换日回首页和连点保护，校验本机存储及备份结构。此前 Mac Chrome 已实测首页、第一关和独立试听页18段连续播放结束。本次修改通过状态模拟，尚未重做真机点击验收；麦克风按用户要求暂缓。
